# Evidencias y registros

> Material formativo para este POC (datos 100 % ficticios de la UNSA). Las referencias a cláusulas se tratan como dato parametrizable según la edición vigente.

Un implementador no entrega solo políticas bonitas: **deja operando registros objetivos** (bitácoras, actas de simulacro, consentimientos, pruebas de restauración y fichas de medidas correctivas) con plazos de retención definidos y control contra alteraciones.

Cuando durante la implantación o revisión interna se detecta que **falta un registro obligatorio**, no basta con «crear el papel ese día»: hay que tramitar formalmente la **no conformidad operativa** siguiendo cuatro reglas estrictas:

1. **Corrección inmediata ≠ acción correctiva:** la corrección contiene el desvío puntual hoy; la acción correctiva modifica el flujo, herramienta o control para eliminar la **causa raíz** y evitar que se repita el próximo trimestre.
2. **Causa raíz ≠ síntoma:** «faltó el archivo» es el síntoma; la causa raíz explica *por qué* falló el proceso de publicación o recordatorio.
3. **Verificación de eficacia posterior:** nunca se verifica eficacia el mismo día en que se implementa la acción; debe mediar tiempo suficiente para observar ciclos reales de operación.
4. **Actualización documental:** si faltaba un punto de control o calendario en un documento PIMS, la ficha debe actualizar dicho documento.
